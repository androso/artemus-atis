# Artemus App

Aplicación web de distribución de vivienda en 2D para el proyecto ATIS de UNIVO.

Artemus permite a propietarios y arquitectos registrar terrenos, definir espacios y preferencias, generar propuestas conceptuales de layout 2D, iterar versiones, aceptar una propuesta y exportarla a PDF/DXF, con revisión por arquitecto.
